レバー引き運動の学習

Motor Learning of Lever Pull Task

レバー引き運動課題を学習中のマウスの脳活動を捉えたサンプルデータセット。広域1光子イメージングによる皮質全体の活動と、2光子イメージングによるM1領域の細胞レベルの活動を含みます。

DATA TYPE
Sample (1 Session)
INDIVIDUALS
2
SESSIONS
14 Days
ANIMAL
Mouse
2p & 1p Imaging M1 / Cortex Lever Pull Task

Abstract

本サンプルデータでは、レバーを適応的に変化する範囲内へと保持することで報酬が得られる運動課題を遂行しているマウスの背側大脳皮質の広域１光子カルシウムイメージング、および前肢関連背側運動領域(以下単純にM1)の第2/3層(L2/3)および第5層(L5)の２光子カルシウムイメージングのデータを各１セッションずつ公開している。

Data Description

各データファイルの詳細な説明は以下の通りです。

📦

Raw Data

  • 📹 Body Camera Movie: RS_Front_210707(日付) jRG10(個体番号).mp4
    マウスの腹側をカメラにより70Hzで計測した動画データ。撮影の開始タイミングはイメージングとは異なる点に注意。
  • 👤 Face Camera Movie: RS_Side_210707(日付) jRG10(個体番号).mp4
    マウスの右側面顔をカメラにより70Hzで計測した動画データ。撮影の開始タイミングはイメージングとは異なる点に注意。
  • 🧠 2p/1p Image Data: .oir (Olympus) / .sifx (Andor) format
    2光子および1光子イメージングの加工前画像データ。512 x 512 pixel、30Hz。
    MATLAB読み込み: 2pはoir2stdData、1pはlvm-file-importを使用
  • 📊 Behavior Data: 210707(日付) jRG10(個体番号) nanataki 5000Hz.lvm
    レバー軌道や課題の状況を5000Hzで計測した行動データおよび同期用のフレーム信号。

📊 Behavior Data Channels (.lvm)

Segment1.dataは行がフレーム数、列が記録チャンネルの行列になっており、以下の値が格納されています（HIGH=5V, LOW=0V）：

Channel Name Description
ch.1 Lever Trajectory レバー軌道（unit: mm）
ch.2 未使用 —
ch.3 Imaging Sync 2p: LOW to HIGH、1p: HIGH to LOW でフレーム取得開始
ch.4 Video Sync Body/Face Camera: LOW to HIGHでフレーム取得開始。両カメラは同期
ch.5 Lever State 1: Base threshold以下, 2: Base以上&Target外, 3: Target zone内
ch.6 Task State 0/1: ITI, 2: Ready, 3: Go, 4: Success, 5: Failure
ch.7 Target Upper Target zoneの上限
ch.8 Target Lower Target zoneの下限
⚙️

Preprocessed Data

  • 🧠 Motion Corrected Image (2p): *_normcorre.mat
    NoRMCorreを用いてnon-rigid motion correctionを行ったimaging data。stdData.image以下に X x Y x Z x Tの4d-matrixとして格納。
  • 🧠 Resized Image (1p): *_image.mat
    rawデータ読み込み後、128 x 128 pixelにリサイズを行ったもの。stdData.I以下に X x Y x Tの3d-matrixとして格納。
  • 📊 CNMF Result (2p): *_CNMF.mat
    CNMFを用いてROI検出を実行した結果。A,C,S,P,b,f: CNMFの出力結果。F_dff, F_dcv, F_denoiseを含む。
  • 🖼️ ΔF/F Image (1p): *_dFF.mat
    各ピクセルに対し、各時間±30secにおける8パーセンタイルの値をF0としΔF/F=(F-F0)/F0を計算した画像ファイル。
  • 📊 Behavior Data: *_task.mat
    task構造体: Fs, lever, lever_state, task_state, bottom, top, frame_trig, video_trig

Analyzed Data (stdData構造体)

解析用に同期処理を行った後のデータ。以下のフィールドを含みます：

  • I: 全時間平均をとったimaging data
  • I_dff [1p]: ΔF/F処理後画像
  • rs_task (構造体): イメージングのフレームレート(30Hz)と同期させたBehavior data
    • lever, lever_state, task_state, bottom, top
  • rs_motions (構造体): イメージングのフレームレート(30Hz)と同期させたDeepLabCutの出力データ
  • cNMF (構造体) [2p]: CNMFを用いてROI検出を実行した結果

Task Paradigm

本課題は、自発的なレバー引き動作をターゲットゾーン(Target zone)内に一定時間(T_target = 200ms)保持することをマウスに学習させます。

🎮 Task States

  • ITI トライアル間の休止期間（Inter-Trial Interval）
  • Ready レバーを基底閾値(0.5mm)以下で1秒以上保持すると遷移
  • Go レバーが基底閾値を越えるとトライアル開始。1000msの制限時間
  • Success ✓ 制限時間内に保持条件を満たすと達成。水報酬が与えられる
  • Failure ✗ 制限時間内に達成できなかった場合

Target zoneは中心を4mmとし、マウスの習熟度（成功数）に応じて±2.5mmから適応的に狭まっていきます。感覚フィードバックとして、レバーがTarget zone内に入っている間は10kHzの純音が提示されます。

Methodology

1

Imaging Setup

トランスジェニックマウス(Thy1-jRGECO1a)を用い、1光子では広域マクロ顕微鏡、2光子では高感度多焦点顕微鏡による計測を実施しました。

2

Image Processing

MATLAB上でNoRMCorreによる動き補正、およびCNMF（2光子）によるROI抽出を行いました。輝度変化(ΔF/F)の算出には、局所的なバックグラウンド減算とパーセンタイルベースのF₀推定を適用しています。
