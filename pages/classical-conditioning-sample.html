古典条件づけの学習過程

Classical Conditioning Learning Process

Abstract

頭部固定マウスに対して古典的条件づけ実験を行いました。条件刺激(CS)として6kHzと10kHzの2種類の異なる音を提示し、無条件刺激(US)として6kHzの場合70%の確率で水を報酬として供給、10kHzの場合30%の確率で水を報酬として供給しました。この実験を2個体のマウスに対して30分間程度、合計17日間行うことで、古典条件づけの学習過程を記録しました。

この記録実験において、脳活動をCa2+プローブを使い広視野1光子顕微鏡（Wide-field 1p）により皮質全体の計測を行いました。さらにマウスの顔および上半身のビデオデータ(Face Camera, Body Camera)を計測しました。またマウスの行動データとしてリックや報酬のタイミングを計測しています(Behavior data)。

Kondo et. al. 2021では、同様のパラダイムでは古典条件づけの学習後のみの1光子イメージと2光子イメージの神経活動の解析を行った結果、背側前頭皮質内側部（dmFrC）が報酬期待行動における起始点であることが分かりました。本データセットでは、その学習にいたるまでにどのように脳内の活動が変化していくかを新しく計測したもののうち、学習後の1個体のサンプルデータを提供します。

Data Description

Raw Data Details

マウス個体番号RCtg_Pv12、RCtg_Pv13の2個体をそれぞれ合計17日間計測しました。1日に4セッションの計測を行っています。

  • Body Camera Movie: 腹側を30Hzで計測したAVI動画。
  • Face Camera Movie: 左側面顔を30Hzで計測したAVI動画。
  • Wide Field 1p: 大脳皮質のCa2+プローブ励起光を30Hzで計測したTIFF画像。2GBごとの分割ファイル。
  • Behavior data: 5000Hzで計測されたLVM形式データ。
Behavior Data Channels (Segment1.data)
Channel Content Description
ch.1 lick sensor (Raw) スパウト接触時HIGH
ch.2 Reward HIGHになった瞬間にポンプ駆動
ch.3 Tone HIGHの間、ch.7の音が吹鳴
ch.4 Imaging Frame フレーム取得タイミング (HIGH=約3V)
ch.5 lick sensor (Binary) 接触時1、非接触時0
ch.7 Tone Frequency 提示中の音の周波数 (kHz)

Analyzed Data Structure (stdData)

MATLAB構造体 stdData には以下の主要なフィールドが含まれます：

  • fct3: 各ROIの神経活動（Zスコア化dF/F）。トライアル種別ごとに音オンセットでアライン (-6〜8s)。
  • flt3: fct3と同様の形式のリックレートデータ。
  • SVDresult: 画像スタックのSVD結果（トップ1000成分）。
  • videoSVD: ビデオMotion EnergyのSVD結果（トップ10成分）。
  • ROIs: ROIマスク配列。
  • Ds: 行動データをイメージングフレーム(30Hz)に合わせてダウンサンプリングしたもの。

Results

Task Paradigm

異なる報酬確率をもつ古典的条件づけのタスク模式図。6kHzの音提示後に報酬を得る確率が高く(70%)、10kHzでは低く(30%)設定されています。

[ Figure: Schematic of Classical Conditioning Task ]

Learning Curve (Lick Changes)

セッションの経過による6kHz（報酬高）と10kHz（報酬低）でのリックの変化。学習が進むにつれて、6kHzの音に対して有意にリック数が増加し、報酬の期待が形成されていることがわかります。

[ Figure: Lick Rate changes over Sessions ]

Methodology

Wide-field 1 photon image processing

各画像スタックは、10個の特徴点（嗅球、前頭血管、ラムダ縫合糸など）を使用してAllen Common Coordinate Framework v3 (Allen CCF) に位置合わせされました。左半球のピクセル活動のみを抽出し、SVDを用いて上位24成分から画像を再構成することでノイズを削減しました。

定位座標に基づき以下の12個のROIを設定しました：dmFrC, dlFrC, M1, S1FL, S1HL, S1m, S1n, S1b, Aud, Vis, PPC, RSC。各ROIの蛍光強度はピクセル平均で算出され、dF/F化の後にZスコア変換を行っています。

Face and Body camera image processing

FaceMapパッケージを使用して口、鼻、ひげ、上半身の部分を識別しました。各ROIの運動エネルギー（フレーム間の絶対差）のSVDを計算し、モーションマスクを生成しています。
